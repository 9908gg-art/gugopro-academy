4.5 TradingView Webhook 直連 API 自動化下單系統建構

在量化交易領域，手動執行策略會帶來情緒干擾與延遲。本專題將手把手教您如何運用 TradingView 的 Webhook 警報系統，結合 Python 中繼伺服器與 HMAC SHA256 簽名，實現毫秒級直連 Binance / OKX / 盈透證券 (IBKR) API 的全自動交易機器人。

一、 全自動 Webhook 下單架構與安全規範

Webhook 是一種即時 HTTP 回呼 (HTTP Callback) 機制。當 TradingView 圖表上的 Pine Script 策略觸發買賣條件時，伺服器會以 HTTP POST 方式發送 JSON 資料封包至您的專用中繼伺服器：

企業級三層安全架構

• API 權限隔離： 交易所 API Key 必須嚴格關閉「提現 (Withdrawal)」權限，僅保留「交易 (Trading)」權限。
• IP 白名單綁定： 中繼伺服器防火牆限制僅接受 TradingView 官方發布的 4 組固定出口 IP 請求 (52.89.214.238, 34.212.75.30 等)。
• HMAC SHA256 訊息簽名： JSON 封包內附帶時間戳與密鑰哈希，防止中間人攻擊或偽造警報。

二、 Pine Script v5 動態 JSON 警報發送寫法

在 Pine Script v5 策略中，使用 alert() 函數動態傳遞交易訊號。建議設定在 alert.freq_once_per_bar_close（K線收盤時），防止盤中訊號閃爍 (Repainting)：

//@version=5 strategy("GugoPro Quant Webhook Strategy", overlay=true, margin_long=100, margin_short=100) // 策略邏輯：20 EMA 與 50 EMA 交叉 ema20 = ta.ema(close, 20) ema50 = ta.ema(close, 50) longCondition = ta.crossover(ema20, ema50) shortCondition = ta.crossunder(ema20, ema50) if (longCondition) strategy.entry("Long", strategy.long) // 發送多頭下單 JSON 封包 alert('{"passphrase": "MY_SECRET_KEY", "action": "BUY", "symbol": "' + syminfo.ticker + '", "qty": 0.1, "type": "MARKET"}', alert.freq_once_per_bar_close) if (shortCondition) strategy.entry("Short", strategy.short) // 發送空頭下單 JSON 封包 alert('{"passphrase": "MY_SECRET_KEY", "action": "SELL", "symbol": "' + syminfo.ticker + '", "qty": 0.1, "type": "MARKET"}', alert.freq_once_per_bar_close)

三、 Python Flask 中繼 Gateway 伺服器代碼

以下為可部署於 AWS / DigitalOcean / Vercel 的輕量 Python 下單中繼站：

from flask import Flask, request, jsonify import hmac, hashlib, time, requests app = Flask(__name__) API_KEY = "YOUR_BINANCE_API_KEY" API_SECRET = "YOUR_BINANCE_API_SECRET" PASSPHRASE = "MY_SECRET_KEY" @app.route('/webhook', methods=['POST']) def webhook(): data = request.get_json() # 1. 密碼驗證 if not data or data.get('passphrase') != PASSPHRASE: return jsonify({"status": "error", "message": "Unauthorized"}), 401 # 2. 解析 TradingView 訊號 symbol = data.get('symbol', 'BTCUSDT') side = data.get('action') # BUY or SELL qty = data.get('qty', 0.01) # 3. 呼叫交易所 API 下單 (例如 Binance Futures API) endpoint = "https://fapi.binance.com/fapi/v1/order" timestamp = int(time.time() * 1000) params = { "symbol": symbol, "side": side, "type": "MARKET", "quantity": qty, "timestamp": timestamp } # 產生 HMAC SHA256 簽名 query_string = '&'.join([f"{k}={v}" for k, v in params.items()]) signature = hmac.new(API_SECRET.encode('utf-8'), query_string.encode('utf-8'), hashlib.sha256).hexdigest() params['signature'] = signature headers = {"X-MBX-APIKEY": API_KEY} res = requests.post(endpoint, headers=headers, params=params) return jsonify({"status": "success", "exchange_response": res.json()}), 200 if __name__ == '__main__': app.run(host='0.0.0.0', port=5000)
