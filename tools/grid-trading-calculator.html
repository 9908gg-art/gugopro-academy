HOW TO READ / GRID RISK

網格線不是收益保證。

單格利潤率會把買入與賣出的雙邊手續費扣除；資金利用率則反映模擬過程中被庫存占用的比例。當 BTC 單方向突破上下限，網格可能停止成交、留下庫存，或觸發止損／止盈，因此必須先定義破網後的停機與重設規則。

實盤前檢查上下限是否以波動與市場結構為依據？止損／止盈是否比網格區間更寬且可執行？單格淨利是否大於手續費、滑價與資金費率？破網後是否限制最大庫存與 API 斷線風險？
