學程晋级制 ‧ 系统化交易學习路徑

從零开始的策略交易學习之旅

欢迎来到 GugoPro 財经教學學院。在這裡，我們依据「學程晋级制」規划了四个學习阶段，從最基礎的观念心态到股票、期貨实务，最后进入高阶的统计套利與量化交易，为您建立全面且系统性的交易逻辑。

學院學习地图

請点选您目前的學习进度，进入对應的系统化學程单元：

Level 1: 🌟 啟蒙阶段 5 个科目

交易啟蒙與心态资金管理

探索市場运作的本质。從股票與期貨的定義开始，學习保证金交易风险、停损紀律、總体经濟 (Fed/CPI) 與全球资产连动，奠定最关鍵的安全边際基礎。

  • 1.1 交易基本常识 (Market Basics)
  • 1.2 交易心态與三大禁忌
  • 1.3 找出支撐與壓力：进出場点與风报比
  • 1.4 總体经濟指标全解析 (Fed / CPI / 非農)
  • 1.5 全球资产连动與美元指数 (DXY / 殖利率)
进入學程
Level 2: 📈 股票學程 3 个科目

股票策略與存股价值投资

專注於股权投资的核心策略。學习葛拉汉价值投资的安全边際、財报分析要領，以及如何筛选高股息标的进行长线存股，並輔以技术分析尋找波段进出場点。

  • 2.1 价值投资大师心法
  • 2.2 高殖利率存股策略
  • 2.3 技术分析與波动交易
进入學程
Level 3: 🌪️ 期貨學程 5 个科目

期貨价差與选择权避险

深入衍生性商品微观机制。從保证金杠杆计算，學习跨期价差套利、跨市場对冲，进而掌握选择权 (Options) 希腊字母與 Covered Call / Cash-Secured Put 实战策略。

  • 3.1 期貨合約與保证金运作
  • 3.2 价差與跨期套利实务
  • 3.3 跨市場对冲與风险平衡
  • 3.4 选择权 (Options) 基礎與希腊字母
  • 3.5 Covered Call 與 Put 打折买股策略
进入學程
Level 4: ⚖️ 量化學程 6 个科目

量化交易與统计套利实战

踏入系统化交易殿堂。运用统计學協整性測试筛选配对标的、Pine Script 程式編寫，並配置 Webhook 直连 API 24小时自动下单與蒙地卡罗壓力測试。

  • 4.1 配对交易实战 (Pairs Trading)
  • 4.2 Pine Script 程式入门
  • 4.3 策略回測與跟单实务
  • 4.4 傳奇大师交易心法應用
  • 4.5 TradingView Webhook 直连 API 自动化下单
  • 4.6 蒙地卡罗模擬與 MDD 壓力測试
进入學程
Level 5: 🪙 加密貨幣學程 2 个科目

加密貨幣與 Web3 交易學程

解密 24/7 高波动资产市場。掌握比特幣 4 年减半週期、链上指标 (MVRV / NUPL) 測顶估底，並运用永續合約资金费率 (Funding Rate) 执行 Delta 中性无风险套利。

  • 5.1 比特幣减半週期與链上数据 (MVRV / NUPL)
  • 5.2 永續合約與资金费率 (Funding Rate) 套利
进入學程
