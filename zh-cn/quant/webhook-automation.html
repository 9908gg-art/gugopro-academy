4.5 TradingView Webhook 直连 API 自动化下单系统建构

在量化交易領域，手动执行策略会带来情緒干扰與延迟。本專題将手把手教您如何运用 TradingView 的 Webhook 警报系统，结合 Python 中繼伺服器與 HMAC SHA256 簽名，实现毫秒级直连 Binance / OKX / 盈透证券 (IBKR) API 的全自动交易机器人。

一、 全自动 Webhook 下单架构與安全規範

Webhook 是一種即时 HTTP 回呼 (HTTP Callback) 机制。當 TradingView 图表上的 Pine Script 策略触发买卖条件时，伺服器会以 HTTP POST 方式发送 JSON 资料封包至您的專用中繼伺服器：

企業级三層安全架构

• API 权限隔离： 交易所 API Key 必須严格关閉「提现 (Withdrawal)」权限，仅保留「交易 (Trading)」权限。
• IP 白名单綁定： 中繼伺服器防火牆限制仅接受 TradingView 官方发布的 4 組固定出口 IP 請求 (52.89.214.238, 34.212.75.30 等)。
• HMAC SHA256 訊息簽名： JSON 封包內附带时間戳與密鑰哈希，防止中間人攻擊或伪造警报。

二、 Pine Script v5 动态 JSON 警报发送寫法

在 Pine Script v5 策略中，使用 alert() 函数动态傳递交易訊号。建議设定在 alert.freq_once_per_bar_close（K线收盤时），防止盤中訊号闪烁 (Repainting)：

//@version=5 strategy("GugoPro Quant Webhook Strategy", overlay=true, margin_long=100, margin_short=100) // 策略逻辑：20 EMA 與 50 EMA 交叉 ema20 = ta.ema(close, 20) ema50 = ta.ema(close, 50) longCondition = ta.crossover(ema20, ema50) shortCondition = ta.crossunder(ema20, ema50) if (longCondition) strategy.entry("Long", strategy.long) // 发送多头下单 JSON 封包 alert('{"passphrase": "MY_SECRET_KEY", "action": "BUY", "symbol": "' + syminfo.ticker + '", "qty": 0.1, "type": "MARKET"}', alert.freq_once_per_bar_close) if (shortCondition) strategy.entry("Short", strategy.short) // 发送空头下单 JSON 封包 alert('{"passphrase": "MY_SECRET_KEY", "action": "SELL", "symbol": "' + syminfo.ticker + '", "qty": 0.1, "type": "MARKET"}', alert.freq_once_per_bar_close)

三、 Python Flask 中繼 Gateway 伺服器代碼

以下为可部署於 AWS / DigitalOcean / Vercel 的輕量 Python 下单中繼站：

from flask import Flask, request, jsonify import hmac, hashlib, time, requests app = Flask(__name__) API_KEY = "YOUR_BINANCE_API_KEY" API_SECRET = "YOUR_BINANCE_API_SECRET" PASSPHRASE = "MY_SECRET_KEY" @app.route('/webhook', methods=['POST']) def webhook(): data = request.get_json() # 1. 密碼驗证 if not data or data.get('passphrase') != PASSPHRASE: return jsonify({"status": "error", "message": "Unauthorized"}), 401 # 2. 解析 TradingView 訊号 symbol = data.get('symbol', 'BTCUSDT') side = data.get('action') # BUY or SELL qty = data.get('qty', 0.01) # 3. 呼叫交易所 API 下单 (例如 Binance Futures API) endpoint = "https://fapi.binance.com/fapi/v1/order" timestamp = int(time.time() * 1000) params = { "symbol": symbol, "side": side, "type": "MARKET", "quantity": qty, "timestamp": timestamp } # 产生 HMAC SHA256 簽名 query_string = '&'.join([f"{k}={v}" for k, v in params.items()]) signature = hmac.new(API_SECRET.encode('utf-8'), query_string.encode('utf-8'), hashlib.sha256).hexdigest() params['signature'] = signature headers = {"X-MBX-APIKEY": API_KEY} res = requests.post(endpoint, headers=headers, params=params) return jsonify({"status": "success", "exchange_response": res.json()}), 200 if __name__ == '__main__': app.run(host='0.0.0.0', port=5000)
