Level 4 學程 ‧ 量化交易與统计套利

量化交易學程 (Quantitative Trading)

欢迎来到 Level 4 學程。本单元是學院的核心精华，專注於利用数學與统计學建立市場中性策略，並利用 Python 进行资料分析與策略回測，最終學习大师的资金控管心法。

返回學院地图
单元 4.1 5 个章节

配对交易实战 (Pairs Trading)

深入探討统计套利與均值回歸原理，學习協整性測试、Z-Score 价差信号计算，以及配对交易的建仓、平仓與风险控管原則。

进入學习
单元 4.2 4 个章节

Pine Script 程式入门 (Pine Script Basics)

學习 TradingView 專属程式語言 Pine Script 的語法逻辑，实战开发出您的第一个自訂指标與均线交叉策略。

进入學习
单元 4.3 4 个章节

策略回測與跟单实务 (Backtesting & Automation)

解讀策略回測报告的关鍵指标，學习防範过度擬合（Overfitting），並配置 Webhook 实现盈透证券自动跟单。

进入學习
单元 4.4 3 个大师

傳奇大师交易心法應用

解构傑西·李佛摩的关鍵点突破與资金管理、理查·丹尼斯的海龜交易法則、以及喬治·索罗斯的市場反身性理論與泡沫週期操作。

进入學习
单元 4.5 2 个章节 + 随堂測驗

TradingView Webhook 直连 API 自动化下单

实现 24 小时无干預程式化下单。學习在 Pine Script 设定警报 JSON Payload，直连 Binance / OKX / IBKR 券商 API。

进入學习
单元 4.6 2 个章节 + 随堂測驗

蒙地卡罗模擬與 Maximum Drawdown 壓力測试

評估策略在最坏市場环境下的极限风险。透过数千次交易顺序重組與破产机率计算，擺脱歷史单一路徑偏误。

进入學习
