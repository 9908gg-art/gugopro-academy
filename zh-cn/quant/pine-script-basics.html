Unit 4.2

TradingView Pine Script 程式交易入门與指标开发

學习如何使用 TradingView 專属的 Pine Script 腳本語言，編寫属於您的技术指标、自动化划线，並为未来的程式化自动交易打下稳固基礎。

1. 什么是 Pine Script？

Pine Script 是由 TradingView 官方开发的輕量级腳本語言。它的語法非常简单好學，类似於 Python，但針对「金融图表」與「技术指标」做了极致的优化。

以往在 Python 中需要寫上百行代碼才能載入歷史 K 线、计算均线並画图；但在 Pine Script 中，您只需要不到 5 行代碼，就能完美计算並繪製出一条自訂技术指标！

2. Pine Script 的两大运行模式

在开始寫程式前，您必須区分 Pine Script 的两種主要程式结构：

  • 指标 (indicator)：用於在图表上繪製视觉輔助工具。例如自訂的 MACD、多重均线通道或我們在配对交易中使用的 Z-Score 价差线。
  • 策略 (strategy)：除了画图，还包含了「买入 (Buy)」與「卖出 (Sell)」的逻辑，可用於在歷史数据上自动执行交易模擬並跑出績效报表。

3. 实战：編寫您的第一个 Pine 均线策略

我們以最经典的「黄金交叉與死亡交叉」均线策略为例。當 5 日均线往上突破 20 日均线时做多，往下突破时做空。以下是完整的 Pine Script 原始碼：

//@version=5
strategy("GugoPro 均线交叉战术", overlay=true)

// 1. 设定输入参数
fastLength = input.int(5, title="快线天数")
slowLength = input.int(20, title="慢线天数")

// 2. 计算移动平均线 (SMA)
fastMA = ta.sma(close, fastLength)
slowMA = ta.sma(close, slowLength)

// 3. 繪製均线到图表上
plot(fastMA, color=color.aqua, title="快线")
plot(slowMA, color=color.orange, title="慢线")

// 4. 定義进出場交叉訊号
longCondition = ta.crossover(fastMA, slowMA)
shortCondition = ta.crossunder(fastMA, slowMA)

// 5. 执行策略模擬
if (longCondition)
    strategy.entry("做多", strategy.long)

if (shortCondition)
    strategy.close("做多")

4. 如何在 TradingView 中执行這段程式？

  1. 打开您的 **[TradingView 图表頁面](https://www.tradingview.com/?aff_id=168714)**。
  2. 点选底部的 **「Pine 編辑器 (Pine Editor)」** 頁籤。
  3. 清除所有默认文字，将上方那段程式碼**复製並貼上**进去。
  4. 点擊右上角的 **「儲存 (Save)」**，接著点擊 **「添加到图表 (Add to Chart)」**。
  5. 此时您的图表上就会繪製出快慢均线，並且在底下会多出 **「策略測试器 (Strategy Tester)」** 看板，展示這套策略在过去歷史中的盈亏成效！
