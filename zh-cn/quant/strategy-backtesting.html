Unit 4.3

TradingView 策略歷史回測與 Webhook 自动化跟单

深入學习量化交易的核心环节：如何科學解讀策略回測报告，以及如何利用 Webhook 技术将 TradingView 訊号对接至盈透证券等券商，实现无人值守的自动化程式交易。

1. 量化交易的核心：歷史回測 (Backtesting)

在量化交易中，我們绝对不憑感觉下单。任何交易逻辑在投入实战资金前，都必須通过**歷史数据回測**的检驗。

當我們在 TradingView 載入一个 Pine Script 策略后，下方的 **「策略測试器 (Strategy Tester)」** 会瞬間模擬过去几年、甚至十几年該策略的每次进出場，並跑出多項关鍵績效指标：

  • 淨利润 (Net Profit)：策略在整个回測期間賺取或亏损的總金額。
  • 胜率 (Win Rate)：获利交易笔数占總交易笔数的百分比。
  • 最大回撤 (Max Drawdown)：帳戶淨值從歷史最高点回落到最低点的最大百分比，這是評估帳戶是否会「断头爆仓」的关鍵风控指标。
  • 获利因子 (Profit Factor)：總获利金額 / 總亏损金額。大於 1.5 代表這是一个相对稳健的策略。

2. 如何防範「过度擬合 (Overfitting)」？

許多初學者在寫 Pine Script 策略时，会拼命优化参数，让歷史回測图表看起来非常完美，這在量化領域称为「过度擬合（过度优化）」。

⚠️ **警告**：过度擬合的策略在歷史数据中賺大錢，但在未来的真实市場中，往往会遭遇严重的亏损。

健全策略的三大黄金法則：

  1. 少即是多：限制您的过濾条件。条件越简单、参数越少，策略的通用性越強。
  2. 樣本外測试 (Out-of-Sample Testing)：使用 2018-2023 年的数据开发策略，然后拿 2024-2026 年「完全未参與优化」的数据进行驗证。
  3. 多标的測试：将您的策略套用在台指期、小道瓊、黄金期貨等不同市場，驗证其是否具备跨市場的生命力。

3. 自动化程式交易：Webhook 跟单运作原理

當您在 TradingView 驗证好一套具有优势的策略后，不需要人工手动下单。我們可以透过 **Webhook 警示** 实现自动跟单：

自动化交易路徑：
1. TradingView 策略触发买入訊号 📈
2. TradingView 伺服器发送 JSON 警示通知到指定的 **Webhook URL** 🌐
3. 接收端伺服器（例如 Python 雲端主机）收到通知，向您的券商 API 下达交易指令 📲
4. 盈透证券 (Interactive Brokers) 帳戶自动执行买入下单 🏛️

4. 如何设定 Webhook 自动下单警示？

  1. 打开您的 TradingView 策略图表。
  2. 点擊图表右上方的 **「警示 (Alert)」** 图示。
  3. 在条件中选择您的 **「自訂策略 (Strategy)」**，此时会自动綁定策略的买卖买卖訊号。
  4. 在「通知」頁籤中，勾选 **「Webhook URL」**，並输入您的交易机器人网址（例如 AutoView, TradingView-to-Broker API 连接器等）。
  5. 在訊息框中，使用 JSON 變数代碼设定下单規格（例如合約口数、委托价格），点擊建立。當訊号来临时，下单将在 1 秒內自动完成！
