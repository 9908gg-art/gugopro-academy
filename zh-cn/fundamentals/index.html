交易啟蒙學程 (Fundamentals)

欢迎来到 Level 1 學程。本单元是每位交易員成功之旅的起点。在此，我們不谈复雜的程式或高深的数學模型，而是把重点放在金融工具的本质、风控制度的防线，以及在大风大浪中克服人性弱点的交易心态心法。

返回學院地图
单元 1.1 3 个章节

交易基本常识 (Market Basics)

探索各类主流金融工具。從股票的所有权份額定義，到期貨合約的本质及到期交割机制，建立全面的市場全景认知，避免因規則不清造成的非交易亏损。

进入學习
单元 1.2 3 个章节

交易心态與三大禁忌

深入心态鍛鍊的難关。解讀散戶在实战中最容易犯下的三大禁忌：过度交易、凹单不认賠、盲目跟单。學习如何培養客观的「贏家机率思维」，克服贪婪與恐惧。

进入學习
单元 1.3 3 个章节

找出支撐與壓力：进出場点如何找出风报比？

學习交易的核心防线。介绍什么是支撐與壓力、如何找出黄金进出場时机與技术停损防线，以及如何利用风报比與动态部位计算，实现大数法則的获利期望值。

进入學习
单元 1.4 3 个章节 + 随堂測驗

總体经濟指标全解析 (Fed / CPI / 非農 / ISM)

學习美联儲貨幣政策與三大核心经濟指标。讀懂通膨、劳动市場與 PMI 荣枯线对股市與大宗商品的影響逻辑，掌握宏观资金大潮。

进入學习
单元 1.5 3 个章节 + 随堂測驗

全球资产连动與美元指数 (DXY / 殖利率倒掛)

拆解跨市場连动密碼。分析美元指数強弱对全球流动性的驅动、美債 2Y/10Y 殖利率倒掛的衰退防空警报，以及黄金與比特幣的避险定位。
