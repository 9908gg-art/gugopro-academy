3.4 选择權 (Options) 基礎与希臘字母风险模型全解

选择權是全球機构法人进行非对稱对沖、波動率套利与多維度风险管理的的核心工具。本专題将帶您透視选择權的四大基本立场、內在价值与时间价值的分解算式，以及四大希臘字母 (Delta, Gamma, Theta, Vega) 的微積分數学本质。

一、 选择權的核心概念与四種基本立场 (Four Basic Positions)

选择權是指买賣双方约定在未來特定到期日 (Expiration Date)，买方有權利按约定履约价 (Strike Price) 买入或賣出标的资产的合约。选择權權利金 (Premium) 由 **內在价值 (Intrinsic Value)** 与 **时间价值 (Time Value)** 組成： $$\text{權利金 Premium} = \text{內在价值} + \text{时间价值}$$

交易立场 權利金流向 最大獲利 最大风险 核心看看法
买进买權 (Buy Call / Long Call) 支付權利金 理论上無限 有限 (仅限所付權利金) 大漲 (看好突破強勢大漲)
賣出买權 (Sell Call / Short Call) 收取權利金 有限 (仅限預收權利金) 理论上無限 看跌或不漲 (看壓在履约价下)
买进賣權 (Buy Put / Long Put) 支付權利金 巨大 (标的跌至 0) 有限 (仅限所付權利金) 大跌 (避险下行或看空暴跌)
賣出賣權 (Sell Put / Short Put) 收取權利金 有限 (仅限預收權利金) 巨大 (标的跌至 0 履约承接) 看漲或不跌 (逢低接股打折策略)

二、 四大希臘字母 (The Option Greeks) 的偏微分风险數学

根據 Black-Scholes 选择權定价模型，合约价值 $V$ 受标的价格 $S$、时间 $t$ 与波動率 $\sigma$ 的影響。希臘字母即為对應變數的偏导數：

1. Delta ($\Delta$) — 标的价格敏感度与動态对沖

$$\Delta = \frac{\partial V}{\partial S}$$ • 意義： 當标的股票价格上漲 $1 时，选择權權利金預期變動的金額。
• 範例： 若某 Call 的 Delta 為 $+0.6$，股票上漲 $10，該 Call 的權利金預期上漲 $6。
• 实战應用： Delta 亦代表該合约到期时處於价內 (ITM) 被履约的统计機率。Delta 近似 0.50 代表价平合约。

2. Gamma ($\Gamma$) — Delta 的加速度与「伽瑪擠壓 (Gamma Squeeze)」

$$\Gamma = \frac{\partial^2 V}{\partial S^2} = \frac{\partial \Delta}{\partial S}$$ • 意義： 當标的价格變動 $1 时，Delta 产生的變動量。价平 (ATM) 合约的 Gamma 最大。
• 伽瑪擠壓效應： 當大量散戶搶购 OTM Call 时，做空 Call 的造市商為了維持 Delta 中性，必須在公开市场緊急追买标的股票現货，引發标的股价螺旋式暴漲（如 2021 年 GME 散戶大战機构事件）。

3. Theta ($\Theta$) — 时间价值流逝速率

$$\Theta = \frac{\partial V}{\partial t}$$ • 意義： 每经过一天，选择權權利金因时间減少而自然损失的金額。
• 流逝曲線特性： 选择權的时间价值损耗並非線性。在臨近到期前的最後 30 天內，Theta 的衰減速度會呈拋物線加速暴跌。賣方 (Seller) 正是利用此一曲線獲利。

4. Vega ($\nu$) — 隱含波動率敏感度与 IV Crush

$$\nu = \frac{\partial V}{\partial \sigma}$$ • 意義： 當隱含波動率 (Implied Volatility, IV) 變動 1% 时，權利金的變動金額。
• IV Crush (波動率壓制)： 财報公佈前市场極度恐慌，IV 飆升拉高 Vega 溢价。财報數據一公佈，不確定性消失，IV 瞬间崩潰，导致即使方向看对，Buy Call 的權利金仍可能因 Vega 暴跌而虧损！
