MODULE 01 / FOUNDATION

固定票息不等於固定市值

債券是借款人依約支付利息並在到期償還本金的債務工具。持有到期時，投資人關注的是信用、現金流與再投資；在到期前出售或持有債券基金時，市場殖利率、信用利差、流動性與期限都會影響價格。當市場要求的殖利率上升，既有較低票息的現金流折現值下降，因此價格通常下跌。

久期可以把一組現金流對利率的小幅變化敏感度壓縮成一個可溝通的數字。它不是到期年限，也不是保證價格變化；久期越長，利率敏感度通常越高。新手常見誤區是只看票面利率、把美國公債視為沒有價格風險，或把殖利率曲線倒掛直接當作精準的股市買賣訊號。

核心觀念：把債券報酬拆成票息、價格變動、再投資、信用利差與匯率，不要只看名目殖利率。

MODULE 02 / METRICS & FORMULAS

價格、久期與殖利率曲線公式

固定票息債券價格可寫成各期票息與本金的現值總和：P = Σ C/(1+y/m)^t + F/(1+y/m)^n，其中 C 為每期票息、y 為年化殖利率、m 為付息頻率、F 為面額。Macaulay 久期是現金流時間的現值加權平均；修正久期約為 Modified Duration = Macaulay Duration ÷（1+y/m）。

小幅變動時可用 ΔP/P ≈ −Modified Duration × Δy。例如修正久期 4.4 年、殖利率上升 0.50%，價格近似下跌 2.2%；實際結果還有凸性，使大幅變動時的曲線關係偏離線性。SEC Investor.gov 將殖利率曲線描述為不同到期年限債務殖利率的相對關係圖，可用於評估債券市場與利率預期，但不是單一方向交易訊號。[1]

假設面額 1,000 元、票面利率 5%、每年付息兩次、到期殖利率 4%、剩餘 5 年，理論價格會高於面額，因為票息高於市場要求報酬。若殖利率再上升 50 bp，而修正久期約 4.4 年，價格的第一階近似變化約為 -2.2%，即約少 23 元。這個數字用來做壓力測試，不應替代完整定價，因為信用利差與流動性可能同時改變。

MODULE 03 / PRACTICE FLOW

實戰：債券配置與進出場檢查

先確認發行人、順位、到期日、票息、付息頻率、贖回條款、信用評等與流動性。再根據資金用途選期限：短期支出不應為了多一點殖利率而承擔過長久期。建立升息、降息、信用利差擴大與匯率變動四個情境，估算價格、票息與本金回收的合計結果。

如果持有債券 ETF，需另外看基金的有效久期、信用配置、到期結構、追蹤方式、費用與折溢價。再平衡時不只比較殖利率，而要比較整個部位對利率和信用的敏感度。把曲線倒掛當作研究提示，搭配通膨、政策、信用利差與自身現金流需求，不用一個訊號做精準擇時。
